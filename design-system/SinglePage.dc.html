SinglePageScreen

The whole organisation on one scrolling page with a sticky jump-nav. It wraps the Activity page's data-dense "in the open" dashboard in the home hero and an editorial section rhythm. Composition-only: it reuses the v0.3 dashboard kit and the DS Card, Callout, Button, Logo and Footer; the jump-nav replaces the standard Header. Recreated from handoff/6 ("Single Page").

Nine bands inside .sds-container, in this order. Each jump target carries scroll-margin-top:74px so the sticky nav never covers a section top.

Section decisions

Sticky jump nav — chrome, not the Header

The one-pager needs in-page navigation, so it swaps the standard Header for a sticky bar that mirrors the same colophon treatment (cream #f1e7dd, 3px saffron keyline). Links are Space Mono 12px/700/.11em uppercase; the active one turns maroon with a 2px underline that scales in. Navigation is anchor links only — CSS scroll-behavior:smooth (scoped via html:has(.sds-single)) does the scrolling; no client JS. Scroll-spy (auto-highlighting the current section) is the one behaviour that needs JS in production — an IntersectionObserver toggling .is-active.

sticky top:0, z:50height 74px = jump offsetpad-block 15pxlink gap 26px

Hero & Recent News

A statement split: serif H1 (clamp → 55px, max 16ch) left, lead + primary/outline Buttons right, aligned to the baseline (align-items:end). Recent News reuses the .sds-catalog__head rule (mono kicker + "All perspectives →" jump to #perspectives) above a .sds-grid-3 of DS Cards with the mono dateline ("FEB 2026 · Gotham Gazette").

Activities — the dashboard core (reused wholesale)

Identical register to the Activity page. A .sds-summary strip (Commits · Active repos +1 · Artifacts · News&posts · a green-pulse "Synced" note), a project .sds-chip filter toolbar, then the .sds-timeline-grid (2fr/1fr): a merged timeline of events / artifacts / posts on the left, a ★ Pinned rail on the right. Rows carry the authorship glyph and diffstat; a .sds-tlpager renders only when >10 items. Filter/sort/pager states are presentational (one active state) — the real page drives them from URL params, matching the server-rendered /activity.

Let’s talk — the single dark moment

The DS Callout maroon band closes the page. The button is overridden to saffron by scoping --sds-primary: var(--sds-gold) / --sds-primary-foreground: var(--sds-ink) on a wrapper around the Button — the brand's "one deliberate dark moment per page" rule. Everything above stays on warm cream.

Responsive behavior (≤820px)

  • Hero (.sds-onehero) and About (.sds-about) collapse to one column; the .sds-timeline-grid and .sds-feed collapse at their existing 720px break.
  • The 6-item jump nav becomes a single horizontally scrollable row (overflow-x:auto, hidden scrollbar) instead of overflowing the page — a JS-free stand-in for a mobile menu. Verified: no page-level horizontal scroll at 375px.
  • The Projects table sits in a .sds-tablewrap (overflow-x:auto) so the wide 4-column grid scrolls inside its own container, never the page.
  • Server-rendered, links only. (Requires the host's box-sizing:border-box reset — present in the site and the Claude Design canvas — which the DS stylesheet does not itself define.)

New CSS (additions only)

  • .sds-spnav / __bar / __nav / __link(.is-active) — the sticky jump nav + smooth-scroll/offset rules.
  • .sds-onehero(__title/__lead/__actions) — the two-column hero.
  • .sds-band / .sds-seclead(__title/__meta) — one-page section rhythm + rule headers.
  • .sds-panel__head, .sds-tdot--post, .sds-pulse — timeline/pinned panel headers, the post dot, the synced pulse.
  • .sds-tlpager / .sds-tlpg — the compact timeline pager; .sds-th-sort — sortable table headers.
  • .sds-about / .sds-about-facts / .sds-fact — the About split + facts card.
  • .sds-tablewrap + the ≤820px block — responsive containment.
