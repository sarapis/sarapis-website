# site/

The Sarapis website and CMS — Payload 3 + Next.js 16 on SQLite.

See the [repository README](../README.md) to run it, [`DEPLOY.md`](DEPLOY.md) to self-host it,
and [`../CLAUDE.md`](../CLAUDE.md) for the architecture, access model and gotchas.

This app began from the [Payload Website Template](https://github.com/payloadcms/payload/tree/main/templates/website)
(MIT, © Payload CMS, Inc.); its upstream documentation covers the pieces kept from it — layout
builder, draft preview, live preview, SEO, search, redirects and form builder.
